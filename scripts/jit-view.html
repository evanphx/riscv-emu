Inside Node’s translated integer loop

Hover, click, or focus a RISC-V line to highlight its emitted x86-64 range. Click locks selection; Escape unlocks it. Links work in both directions.

How to read the mapping

Ranges are recorded by the direct emitter during compilation. Fused pairs and grouped reads share a range. A loop-entry range can include a hoisted translation used by later reads. Retirement accounting at a boundary belongs to that emission range, not necessarily to the selected guest instruction alone. Empty ranges mean no host bytes were emitted.

Entry register loads and out-of-line slow paths, side exits, chaining, and return code are shared infrastructure, not one-to-one instruction translations. They remain visible but are labeled separately. This is generated code, not a dynamic instruction trace.

Register allocation and reproduction

r12 = Cpu, r13 = retired count, r14 = entry guest PC, rbp = TLB base (or mmap bias). Other host registers are temporaries. Cpu-relative loads/stores access emulator state; not every host memory operand is a guest memory access.
